# 操作指导：监控中心

> 服务器监控 / 缓存监控 / 在线用户 / 日志管理 四个监控页面的操作说明。
> 查看类操作需要 `monitor:view`；**清理/日志文件/强制下线**需要管理员
> （后端 `require_superuser` 或 `monitor:manage` 强制校验）。

## 1. 服务器监控（/monitor/server）

展示服务端运行状态，用于观测服务器健康：

| 区块 | 内容 |
|---|---|
| 仪表盘 | CPU 使用率（逻辑核心数）、内存（总量/已用/可用）、磁盘（工作目录所在分区） |
| 系统信息 | 操作系统、主机名、架构、**Python 版本**、工作目录、启动时间 |
| 进程信息 | 服务进程 PID、内存占用、CPU、运行时长 |
| **日志文件**（管理员） | 日志目录清单（按修改时间倒序），支持**查看尾部**（默认 200 行对话框）与**下载** |

- 数据来源：`GET /server-info`（psutil 实时采集，CPU 采样在线程池执行不阻塞事件循环）；
- 日志浏览安全：仅管理员、文件名白名单、路径穿越拒绝（穿越尝试返回 404）；
- 大文件建议用「查看尾部」而不是下载整份（error.log 可达数 MB）。

## 2. 缓存监控（/monitor/cache）

### 2.1 Redis 运行状态

版本、运行模式、运行时长、已用内存/峰值、连接客户端数、当前库键总数、命中率、命令调用统计（Top10）。
Redis 不可用时整页降级为"缓存服务不可用"提示（HTTP 仍 200）。

### 2.2 缓存数据与清理（管理员）

「缓存数据」表格列出全部业务缓存分组及当前键数量：

| 分组 | 键前缀 | 可清理 |
|---|---|---|
| 用户信息缓存 | `user:info:*` | ✓ |
| 用户权限缓存 | `user:perms:*` | ✓ |
| 菜单全量缓存 | `menu:all` | ✓ |
| 字典缓存 | `dict:*` | ✓ |
| IP 规则缓存 | `ip:rules` | ✓ |
| 令牌黑名单 | `token:blacklist:*` | ✗ 安全红线（清理会使已登出令牌复活） |

- **快速清理**：行内按钮（popconfirm 二次确认）；
- **清空全部缓存**：右上危险按钮——逐组清理全部可清理业务组，
  **不含**令牌黑名单与限流计数键（不会让已登出令牌复活、不重置限流窗口）；
- 清理后相关数据回源数据库自动重建（用户下次请求重新缓存）。

## 3. 在线用户（/monitor/online)

- 实时会话列表（Redis `online:user:*` + 内存镜像降级），支持用户名过滤与分页；
- **强制下线**：删除会话并把对应访问令牌拉黑，该用户下一次请求即被拒绝
  （其 WebSocket 连接也会因令牌校验断开）；
- 注意：强制下线作用于当前 access_token；若对方持有 refresh_token 仍可重新登录获取新令牌——
  需要彻底禁用请使用用户管理的「停用」。

## 4. 日志管理（/monitor/log/login、/monitor/log/operation)

- 登录日志：成功/失败记录（安全审计数据源，含 IP/浏览器/系统/时间）；
- 操作日志：非 GET 请求审计（请求体敏感字段已脱敏），含"操作概要"列；
- 均支持批量删除与清空（`log:delete` 权限）；操作日志正文上限 4000 字符。

## 5. 实时通知（顶栏铃铛）

- 登录后自动建立 WebSocket（断网指数退避重连，心跳 25s）；
- 管理员发布/启用公告 → 全员实时收到（红点 + 弹窗 + 铃铛摇晃）；
- 切走标签页会断开连接、切回自动重连（设计如此，节省服务端连接）。
