# 操作指导：认证与账户

> 登录 / 登出 / 密码 / 头像 / 个人安全日志 的用户侧操作说明。
> 认证机制原理见[认证与安全](../features/auth-security.md)。

[← 返回文档导航](../README.md)

---

## 1. 登录

- 账号密码登录（验证码本地方案，可按需替换短信/OAuth）；
- 登录限流：同 IP 对 login/register 有专属限额（生产 20/分钟），超限返回 429 并提示稍后再试；
- 登录成功后：动态路由下发、WebSocket 实时连接建立、跳转欢迎页。

## 2. 登出

- 右上角用户菜单 → 退出登录；
- 行为：后端吊销 access_token 与 refresh_token（双令牌进黑名单）→
  本地清空登录态 → 断开实时连接 → 回登录页；
- 令牌过期或后端判定未认证时，前端也会自动登出（401 处理）。

## 3. 修改密码（个人中心 → 安全设置）

- 需校验旧密码；新密码 ≥8 位；
- 修改成功后建议重新登录（当前实现：改密后旧 access_token 在有效期内仍可用，
  主动吊销为已知遗留项）。

## 4. 个人资料与头像（个人中心 → 个人信息）

- 可改昵称/姓名/邮箱/手机号/性别/简介；
- 头像上传：≤2MB，jpg/jpeg/png/gif/webp；保存后通过 `/media/avatars/` 访问；
- 更新成功会同步刷新顶栏头像。

## 5. 个人安全日志（个人中心 → 安全日志）

- 展示当前账号的登录记录（成功与失败、IP、浏览器、系统、时间）；
- 服务端分页；异常的失败记录提示账号可能被尝试爆破，建议改密。

## 6. 忘记密码

- 当前版本未提供自助找回（无邮件服务集成）；
- 管理员可在用户管理页对该账号「重置密码」。
