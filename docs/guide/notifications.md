# 操作指导：通知公告与实时推送

> 通知公告的管理操作与实时触达机制。
> 机制原理见[实时消息](../features/realtime.md)。

[← 返回文档导航](../README.md)

---

## 1. 发布公告（管理员）

- 入口：系统管理 → 通知公告 → 新增；
- 字段：标题（必填，≤128 字）、内容（≤65535 字）、类型（1 通知 / 2 公告）、状态；
- **发布即推**：保存时若状态为"启用"，所有在线用户立即收到顶栏弹窗与铃铛红点；
- 保存时状态为"关闭"则不推送（仅入库，后续启用时再推送）。

## 2. 编辑与重新推送

- 更新公告后若处于启用状态，会**再次广播**最新内容给在线用户；
- 不希望打扰用户时：先停用再编辑，或直接编辑时保持状态为关闭。

## 3. 用户侧接收

- 顶栏铃铛：红点提示 + 未读条目按类型分 Tab（通知/公告）；
- 新消息到达时弹 ElMessage 提示 + 铃铛摇晃动画；
- 点击条目查看详情；历史公告也可在通知公告列表页查看（有 view 权限时）。

## 4. 常见问题

| 现象 | 说明 |
|---|---|
| 没有收到实时推送 | 确认浏览器标签页处于前台（切后台会断开 WS，切回自动重连）；确认公告状态为启用 |
| 推送延迟 | 心跳 25s + 重连退避最长 15s；正常网络下为秒级 |
| 离线用户能收到吗 | 不能。WS 只推在线连接；离线用户靠公告列表页主动查看（无离线队列） |
