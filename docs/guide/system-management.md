# 操作指导：系统管理

> 覆盖用户 / 角色 / 菜单 / 部门 / 岗位 / 字典 / 参数配置 / IP 规则的日常操作要点。
> 每个页面的完整 CRUD 能力一致（新增/编辑/删除/批量删除/搜索/分页），此处只记录
> 易错点与模块特有操作。

[← 返回文档导航](../README.md)

---

## 1. 用户管理（/system/user）

- 新增用户：用户名 ≥3 位、密码 ≥8 位、邮箱需合法；可同时分配部门/岗位/角色；
- 重置密码 / 分配角色：行操作「更多」菜单（仅管理员语义的敏感操作）；
- 状态开关：停用后该用户立即无法通过鉴权（缓存同步失效）；
- 头像：个人中心上传（2MB，jpg/jpeg/png/gif/webp），旧头像文件不自动清理（已知遗留）。

## 2. 角色管理（/system/role）

- 新建角色时可直接勾选菜单授权；已有角色走行操作「菜单权限」；
- **数据权限**：行操作「数据权限」抽屉（五档，见[RBAC](../features/rbac.md#3-数据权限datascope-五档)）；
- 任何角色权限变更即时生效（相关用户权限缓存批量失效）。

## 3. 菜单管理（/system/menu）

- 三类节点：目录（0）/ 页面（1）/ 按钮（2）；
- 新增页面菜单的 `component` 需是前端视图路径（如 `system/user/index`），
  动态路由据此懒加载 `web/src/views/{component}.vue`；
- **启用开关**：行内开关调用 `PUT /menu/{id}/status`，停用的菜单不下发动态路由；
- 删除限制：存在子菜单时禁止删除。

## 4. 部门管理（/system/dept）

- 树形结构；支持行内新增子部门；
- 部门编码唯一（保存失败时系统自动生成唯一编码）；
- 部门树同时服务于用户列表的数据权限过滤。

## 5. 字典管理（/system/dictionary）

- 左树（字典类型）右表（字典项）布局；
- **新增字典**：右上主入口按钮；新增子项：树节点右键菜单或选中后主按钮；
- 字典项被业务下拉消费（`useDict` 组合式，模块级缓存）——
  修改字典后其他页面的下拉需刷新页面才会更新（`clearDictCache` 暂无调用入口，已知遗留）。

## 6. 参数配置（/system/config）

- 键值对系统参数；key 唯一；
- 业务代码通过服务层读取，修改后立即生效（无缓存中间层）。

## 7. IP 规则（/system/ip-rule）

- 黑名单 / 白名单两类规则，保存后自动刷新中间件缓存；
- **多进程部署注意**：刷新只作用于处理该请求的 worker，生产多 worker 部署
  需重启或滚动刷新才能全量生效（已知遗留，见架构评估报告）；
- 白名单优先于黑名单。

## 8. 通知公告（/system/notice）

- 公告类型：1 通知 / 2 公告（对应顶栏铃铛的不同 Tab）；
- 发布（isActive=1）或更新为启用状态时，**实时推送**给所有在线用户；
- 内容上限 65535 字符（防超大广播）。
