## Description: <br>
Guides agents in designing or reviewing Vue 3 + TypeScript project structure, component boundaries, composables, route composition, Pinia ownership, API and error handling defaults, styling boundaries, directives, and repository-wide Vue conventions. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[bovinphang](https://clawhub.ai/user/bovinphang) <br>

### License/Terms of Use: <br>
MIT <br>


## Use Case: <br>
Developers and coding agents use this skill to structure and review Vue 3 + TypeScript applications, especially component boundaries, composables, Pinia state ownership, routing, API and error handling, and project conventions. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can guide agents to propose broad Vue architecture or code changes that may not fit a specific repository. <br>
Mitigation: Review generated changes against the repository's existing conventions and tests before applying or deploying them. <br>
